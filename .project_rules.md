# Project Rules: Wanali - Sri Lankan Elephants & Tuskers Registry

## 1. Architecture & Stack Mandates
- Technology Stack: Vite + Vanilla JavaScript (ES6 Modules) + Modular Plain CSS
- Strictly Prohibited: No React, Vue, Svelte, Tailwind CSS, Bootstrap, or heavy third-party UI libraries
- 200-Line Limit: Every JavaScript module (.js) and CSS stylesheet (.css) must strictly remain under 200 lines. Proactively modularize before reaching 180 lines
- Static Multi-Page Output: Every tusker entry is pre-rendered as a static HTML file under /elephants/ for zero-JS crawling, SEO, and lightning-fast loading

## 2. Frontend Design Principles
- Subject-grounded design reflecting Sri Lanka's dry-zone scrub forests, misty highlands, ancient stone inscriptions, and sacred temple processions
- Palette: Forest obsidian, deep moss, ivory gold, terracotta memorial crimson, and granite parchment
- No generic AI cliches: No cookie-cutter cards, no tracked-out all-caps labels, no gratuitous glow effects
- Clean semantic HTML5: main, nav, header, footer, section, article, dialog, aside

## 3. Data Integrity & Conservation Ethics
- Accurate documentation of Sri Lanka's iconic wild tuskers and sacred temple custodians
- Transparent tracking of status: Alive, Deceased, Historical
- Objective documentation of cause of death (poaching, electrocution, jaw-bombs/Hakka Patas, human-elephant conflict, natural old age) to raise conservation awareness
